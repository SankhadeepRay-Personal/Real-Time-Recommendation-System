Metadata / Catalog
Central repository for managing data assets, schemas, ownership, and discovery across all layers.
Monitoring & Alerting
Tracks pipeline health, data freshness, latency, and quality metrics, triggering alerts on anomalies.
Data Lineage & Audit
Provides end-to-end visibility into data origins, transformations, and usage for governance and debugging.
Checkpointing / Fault Tolerance
Ensures Spark Streaming jobs can recover from failures with exactly-once processing guarantees.
Web / Mobile App Clickstream Events
Real-time user interaction data such as page views, product clicks, add-to-cart actions, and purchases.
Product Master Data
Daily batch feed containing all product attributes like category, brand, price, and description.
Customer Master Data
Daily batch feed with customer profile information, demographics, and segmentation details.
Kafka Producers
Services within the web/mobile backend that publish event data to Kafka topics.
Kafka Topics (clicks, views, etc.)
Durable, ordered logs of events that act as a buffer between producers and consumers.
Batch Ingestion Jobs (Daily Product & Customer Load)
Scheduled jobs (e.g., using Airflow, Spark) that load dimension data into the Bronze layer.
Streaming Read from Kafka
A Spark Streaming job that continuously consumes events from Kafka topics.
Batch Read for Customer Dimension
Reads the raw customer dimension table for use in enrichment steps.
Batch Read for Product Dimension
Reads the raw product dimension table for use in enrichment steps.
Raw Clickstream Events Delta Table (Append-only, schema evolution, audit fields)
Stores raw, unaltered event data from Kafka, preserving the full history for replayability and auditing.
Raw Customer Dimension Delta Table (Daily snapshot)
A daily snapshot of the customer master data, stored in Delta Lake format.
Raw Product Dimension Delta Table (Daily snapshot)
A daily snapshot of the product master data, stored in Delta Lake format.
Parse / Extract Event Fields (user_id, session_id, event_type, etc.)
Transforms raw JSON/Avro event strings into structured columns for easier processing.
Data Quality Checks (deduplication, null handling, late events)
Applies rules to filter out bad data, handle duplicates, and manage out-of-order events.
Join with Product Dimension
Enriches event data with product attributes like category and brand by joining with the product dimension table.
Join with Customer Dimension
Enriches event data with customer attributes like segment and location by joining with the customer dimension table.
Behavioral Feature Engineering
Creates high-level features from user behavior, such as session duration or purchase frequency.
Derived Features Delta Tables (Most Viewed Category, Favorite Brand, Price Preference)
Aggregated tables storing user-level features, which are the primary input for the recommendation models.
Business Metrics (CTR, Conversion, etc.)
Aggregated business intelligence tables for monitoring recommendation performance and user engagement.
Recommendation Feature Store / Serving Table
A low-latency table optimized for serving features to the real-time recommendation logic.
Recommendation Logic / Models (rule-based, collaborative, ranking)
Applies algorithms to generate recommendation candidates and rank them for each user or session.
Top-N Recommendations per User / Session
The final output: a list of the top N recommended product IDs for each user or active session.
Campaign / Notification Systems
Uses recommendation outputs to power personalized email, SMS, or push notification campaigns.
BI Dashboard / Monitoring
Visualizes business metrics and recommendation performance for analysis by business stakeholders.
Recommendation API / Microservice
A low-latency API endpoint that serves personalized recommendations to front-end applications.
Website / Mobile App Personalization
The end-user application that displays the recommendations in 'Recommended for You' carousels and other widgets.
